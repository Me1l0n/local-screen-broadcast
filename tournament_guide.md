# 🎮 Tournament Stream — Полный гайд на день трансляции

---

## 📦 Что это за программа

Локальный сервер на Node.js. Запускается на стримерском ПК. Все устройства в одной Wi-Fi/LAN сети. Никакой внешний интернет для видео не нужен — всё идёт внутри сети.

```
Стримерский ПК (сервер)
       │
       ├── Игроки заходят на  https://192.168.x.x:3456/stream  → раздают экраны
       └── Ты открываешь      https://localhost:3456            → видишь все экраны
```

---

## 🚀 Запуск — основной способ

**Дважды кликнуть на `run.bat`** в папке проекта.

Скрипт сам:
1. Проверит, установлен ли Node.js
2. Установит Node.js если нет (через winget или скачает MSI)
3. Установит зависимости (`npm install`)
4. Запустит сервер

---

## 🔧 Ручная установка (если run.bat не сработал)

### Шаг 1 — Установить Node.js

Скачать с официального сайта: **https://nodejs.org/en/download**

Выбрать: **LTS версия → Windows Installer (.msi) → 64-bit**

Установить с настройками по умолчанию. После установки закрыть и открыть заново командную строку.

Проверить:
```
node -v
```
Должно вывести что-то вроде `v22.14.0`.

---

### Шаг 2 — Установить зависимости

Открыть **командную строку** (Win+R → `cmd`) в папке проекта:
```
cd /d D:\pitonchik\Peredachik
npm install
```
Подождать пока скачаются пакеты. Появится папка `node_modules`.

---

### Шаг 3 — Запустить сервер

```
node server.js
```

Или через переменную окружения с портом:
```
set PORT=3456 && node server.js
```

## ⚠️ Предупреждение браузера о сертификате (ОБЯЗАТЕЛЬНО)

При первом входе Chrome покажет **"Ваше подключение не защищено"**.

Это **нормально** — сертификат самоподписанный (сервер внутри сети).

**Что нажать:**
1. `Дополнительно`
2. `Перейти на сайт tournament.local (небезопасно)`

Это нужно сделать **один раз** на каждом устройстве.

## 🎮 Инструкция для игроков (раздай им это)

1. Открыть **Chrome** на своём ПК
2. Перейти по ссылке: `https://192.168.X.X:3456/stream`
3. Нажать `Дополнительно` → `Перейти на сайт`
4. Нажать кнопку **"Начать трансляцию"**
5. Выбрать **весь экран** (не окно и не вкладку!)
6. Нажать **"Поделиться"**
7. **Не сворачивать окно браузера** — оставить его видимым (можно перенести на второй монитор или в угол)

> [!WARNING]
> Если игрок выберет "Окно" вместо "Экран" — трансляция будет только окна игры, без интерфейса. Для Dota 2 лучше выбирать весь экран.

## 📺 Управление — Панель организатора

### Переключение между игроками

| Клавиши | Действие |
|---|---|
| `1` — `9` | Открыть игрока 1–9 на весь экран |
| `0` | Открыть игрока 10 |
| `Numpad 1–9 / 0` | То же самое, но на цифровом блоке |
| `Esc` | Выйти из полного экрана (вернуться к сетке) |
| `Двойной клик` на видео | Открыть игрока на весь экран |

### Как работает переключение (умное)

При нажатии на клавишу игрока:
1. Игрок включается и начинает слать картинку
2. Ждём пока появится реальное изображение
3. + 1 секунда для стабилизации
4. Переходим в полный экран с уже живой картинкой
5. Через 3.5 секунды — предыдущий игрок ставится на паузу (экономия ресурсов)

> [!NOTE]
> Если нажать клавишу пока идёт переключение — запрос встанет в очередь и выполнится после. Паника и быстрое нажатие всё равно приведёт к правильному результату.

### Сетка (главный экран)

Когда не смотришь никого в полный экран — все карточки показывают **замороженный последний кадр** + статус сигнала. Видео не воспроизводится — экономия ресурсов.

## ⚙️ Настройки качества (на ПК каждого игрока)

На странице `/stream` у игрока есть выбор:

**FPS:** `15` / `30` / `60`
- Рекомендация: **30** — достаточно для трансляции, не грузит
- **60** — если сеть хорошая и ПК мощный

**Битрейт:** `Авто` / `10 Мбит` / `25 Мбит` / `50 Мбит`
- Рекомендация: **10 Мбит** — оптимально для LAN
- **25 Мбит** если сеть стабильная и хочется качество лучше
- **Авто** может перегрузить слабые ПК

---

## 🖥️ Важно: Аппаратное ускорение в Chrome

Без аппаратного ускорения CPU будет 100% и кадры будут пропускаться.

**На каждом ПК игрока проверить:**

1. Открыть Chrome → три точки → **Настройки**
2. Прокрутить вниз → **Система**
3. Включить: **"Использовать аппаратное ускорение (при наличии)"**
4. Перезапустить Chrome

**Дополнительно проверить:**
- Перейти в `chrome://gpu`
- Найти строку **"Video Encode: Hardware accelerated"**
- Если написано `Software only` — значит GPU не поддерживает кодирование, CPU будет грузиться

## 🔧 Порт по умолчанию

Сервер запускается на **порту 3456**.

Если порт занят — изменить в `run.bat`:
```
set PORT=3456
```
Заменить 3456 на любой другой (например 8443).

Остановить (Ctrl+C) → запустить `run.bat` снова.

## ❗ Частые проблемы

### Игрок видит "Доступ закрыт" (403)
→ Он пытается открыть `https://localhost:3456` (панель организатора).
→ Дать ему правильную ссылку: `https://192.168.x.x:3456/stream`

### Видео чёрное / не появляется
→ Игрок выбрал **вкладку** вместо **экрана** — попросить переключить трансляцию.
→ Или игрок свернул браузер — попросить развернуть.

### "node не является внутренней командой"
→ Node.js не установлен или не добавлен в PATH.
→ Переустановить Node.js с **nodejs.org**, перезапустить ПК.

### Высокая нагрузка на CPU у игрока
→ Выключить 60 FPS, поставить 30.
→ Снизить битрейт с 25 до 10 Мбит.
→ Включить аппаратное ускорение в Chrome.

### Игрок подключился, но номер не тот
→ Номера выдаются по порядку подключения. Попросить нужного игрока переподключиться последним.

### Переключение зависло (долго чёрный экран)
→ Истёк таймаут 5 сек — сработал автопереход.
→ Слабое соединение у игрока или он свернул браузер.

### Оба игрока на паузе
→ Произошёл быстрый переключение. Нажми клавишу игрока снова — переключится нормально.

## 🔒 Безопасность

- **Панель организатора** (`https://localhost:3456`) — открывается **только** на том ПК где запущен сервер. Игроки физически не могут её открыть.
- **Игроки** видят только свою страницу трансляции.
- Сервер работает только внутри LAN — наружу не выходит.
